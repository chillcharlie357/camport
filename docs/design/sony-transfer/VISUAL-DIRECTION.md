# 银灰工作台 / v2

保留已认可的 B 布局与全部页面，只修改配色、字体及装饰性文字。

## 视觉判断

上一版的橄榄黑、琥珀按钮、米灰画板，以及大标题前的小标签，叠加后像一套通用的“高级工具”模板。这版从相机银色机身与桌面文件浏览器取材：以中性面板承托照片，控制色彩出现的位置。

## 配色

- 画布 #F3F4F5
- 面板 #FFFFFF
- 主文字 #252A30
- 次要文字 #66717E
- 主按钮 #303841，白字
- 选中与进度 #3C6489
- 成功 #3B755B，限语义反馈

## 字体

中文使用 Noto Sans SC（思源黑体体系），西文与数字使用 IBM Plex Sans；两者均随稿件打包，支持离线查看。文件名为比例字体，仅对数字采用等宽数字特性，不使用编程式等宽字体。

标题 26/500，页面标题 18/500，正文 14/400，说明信息 12/400。避免人为压缩中文字距、密集全大写标签和把字重全部加粗。

## 保持与删减

保持两列大图、动态格式筛选、固定导入入口和原有流程。删去重复的“你的相机”眉题，降低界面强调色面积。大图预览仍使用深色背景，帮助检查照片。

## 使用的插件

frontend-design@claude-plugins-official（本机已安装且启用）；依据其“从产品内容推导视觉方向”“先定义颜色与字形”“删去无信息的装饰”原则完成此轮。
