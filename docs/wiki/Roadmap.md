# 路线图

## 已完成

- Flutter 四平台工程骨架：Android、iOS、macOS、Windows。
- PTP/IP 传输层与编解码器，含命令串行、超时、保活、背压和连接关闭释放。
- Sony PTP/IP 相机适配器：握手、元数据分页、按需缩略图、原片导入和取消。
- 持久化导入队列与平台后台通道。
- 同名 RAW/JPG/PNG 合并与格式筛选。
- CI/CD：PR 检查 + main 合并后自动版本号并发布 Android APK、macOS 压缩包、Windows 压缩包；iOS 仅编译检查。

## 进行中

- 仓库与应用命名。
- GitHub Wiki 整理。
- 真实 ZV-E10 连接与传输验收。

## 下一步

- 在真机 ZV-E10 上验证 SSDP 发现、PTP/IP 握手、图库、缩略图与原片导入。
- 建立无线预览冷启动首图和冷连接到可用图库的真实耗时基线。
- 根据真实机型补全 Sony 会话协商的模型分支。
- 验证 Android 后台导入与断线恢复。

## 后续版本

- iOS 物理设备本地网络权限与后台传输验证。
- macOS/Windows 桌面端完整验证。
- USB/MTP/PTP 导入。
- 评分写回（需先独立验证目标机型协议能力，再设计实现）。
- 遥控拍摄与实时监看。
- 通过 `CameraSession` 注册表接入其他相机品牌和传输协议。

## 明确不在首版

- 云同步、账号、AI 修图。
- 直播推流、多机位、外置存储云盘。
- 声称支持全部 Sony 机型或全部相机协议。
