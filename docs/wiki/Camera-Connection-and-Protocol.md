# 相机连接与协议

首版只实现 Sony 相机无线传输路径，协议层基于 PTP/IP。真实机型行为仍需硬件验证；本文记录当前代码事实，不是兼容性承诺。

## 发现

- 使用 SSDP 发现相机，按设备描述和 USN 识别。
- 区分 PC Remote 与真实媒体传输，避免把遥控端点当作文件端点。
- 只在用户主动连接时发现，不持续扫描任意网段。

## PTP/IP 连接

- 建立命令连接和数据连接，完成握手后才发送命令。
- 校验会话、GUID、事务 ID、长度、phase 和 EndData。
- 命令串行执行；`tid=0` 不消耗从 1 开始的默认事务 ID。
- 设置 I/O 进展等待和 `sink.flush` 上限超时、可选保活间隔、最大包大小。
- 数据接收按块 flush 背压，`RawSocket` 每次最多读取 64 KiB，取消按块释放，避免累积。
- 连接中断、超时或 `close` 会释放活动命令和排队命令。

## 对象枚举与元数据

- 通过 ObjectInfo 获取文件名、格式、大小和可用拍摄时间等元数据。
- 目录分页读取，首页只读本页，避免一次拉取整卡元数据。
- 用稳定的存储信息哈希构建缩略图缓存键，避免错配缓存。

## 缩略图

- 使用 `GetThumb` 按需请求。
- 只解码 JPEG/PNG 缩略图，限制头部像素尺寸；RAW 不作为缩略图解码。
- 原图预览在用户明确载入或导入时才请求，不使用原图生成图库缩略图。

## 原片下载

- 先 `describeFile` 再用 `expectFile` 校验源版本和预期长度。
- 优先使用相机在 `GetDeviceInfo` 中实际报告的 Sony 分块读取：ZV-E10 / Creators' App 为 `SDIO_GetPartialLargeObject (0x9219)`，旧 IEM 固件为 `0x9211`，参数都是对象句柄、低位偏移、高位偏移、单块不超过 1 MiB。
- 退回标准 `GetPartialObject (0x101b)` 或 `GetObject (0x1009)`；不符合期望字节数时回滚到已提交进度。
- 仅支持 `GetObject` 的相机重头下载，不声称支持断点续传。
- 下载过程进行字节计数与校验，成功校验后才发布最终文件。

## 扩展点

- `CameraSession` 接口把“能力”和“协议”解耦。
- `CameraSessionRegistry` 根据目标返回对应会话，未来可加入其他相机品牌的适配器。
- 首版 `canDownloadOriginals` 依据能力操作码判断，不在 UI 中写死机型分支。
