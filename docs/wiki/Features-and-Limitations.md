# 功能与限制

## 已实现（代码级）

### 连接

- 用户主动触发的 SSDP 局域网发现，不扫描任意 TCP 地址。
- `CameraSessionRegistry` + 工厂注册，首版仅注册 Sony PTP/IP 会话，接口允许未来加入其他相机。
- 强身份优先使用序列号和型号，否则使用有效 UDN；弱身份使用随机隔离命名空间，不复用持久缓存。

### 图库与预览

- 图库按页读取元数据，首页只读取本页。
- 缩略图按可见区域和下一行请求，最多 2 个并发；单张预览复用缓存。
- 会话内 32 MiB LRU；磁盘缓存有界并可清理。
- 进入图库不自动下载原片；原片只在用户打开预览或导入时请求。

### 筛选与合并

- 按文件类型筛选（RAW、JPEG、PNG、MP4 等）。
- 同名 RAW/JPG/PNG 合并为一项，不改变源文件。

### 原片导入

- 只下载用户选择的文件。
- 保持源字节，不缩小、不转码、不重编码。
- 下载用临时文件，完成校验后才发布；失败可回滚。
- 持久化队列支持暂停、取消、重试和重启恢复。
- 仅在协议确认支持可靠的字节范围语义时续传；`GetObject` 单独路径会从头重来，不伪报续传。

### 平台后台

- Android/iOS 通过原生 MethodChannel 接入前台服务或后台会话；桌面端持久化队列状态。
- 断线后恢复未完成项，不重复下载已完成项。

## 安全边界

- 默认本地处理，无云账号也可浏览和导入。
- 不删除文件、不触发拍摄、不修改相机设置。
- 只允许 LAN IPv4 目标；生产代码不提供 `allowLoopback` 绕过。
- 只有 `GetThumb` 数据进入图像解码器，禁止解码 RAW 原片来生成缩略图。
- 缩略图、队列和偏好存储带版本，损坏数据可恢复，普通偏好不存敏感凭据。
